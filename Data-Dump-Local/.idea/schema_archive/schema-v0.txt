# Tentative Schema

1. Customer Node
Properties:
// Identity
- uuid: String (primary key)
- name: String
- phone: String
- alternate_numbers: List[String]

// Loan Context
- loan_number: String
- product_name: String (Two-Wheeler Loan, Personal Loan, etc.)
- emi_amount: Float
- total_payable_amount: Float
- pending_emi: Integer

// Profile
- language_preference: String (HINDI/ENGLISH)
- customer_gender: String (male/female)
- customer_state: String

// Metadata
- total_calls: Integer
- first_call_date: DateTime
- last_call_date: DateTime
- created_at: DateTime
- updated_at: DateTime

2. Conversation Node
Properties:
// Identity
- uuid: String (primary key)
- name: String (Conversation #{call_sequence})
- call_sequence: Integer

// Call Behavior
- customer_tone: String (Cooperative/Frustrated/Defensive/Neutral)
- objection_raised: String (charge_dispute/financial_hardship/technical/already_paid/none)
- payment_discussed: String (UPI/Card/Cash/None)

// Outcome Signals
- payment_attempted: Boolean
- ptp_given: Boolean
- escalated: Boolean


3. Disposition Node
Properties:
// Classification
- code: String (ONP/PTP/FPTP/RTP/DIR/etc.)
- name: String (human-readable)

// PTP Specifics (only if applicable)
- ptp_date: DateTime (null if not PTP/FPTP)
- ptp_honored: Boolean (null initially, updated later)

// Actionable Summary
- intent: String (brief customer intent from disposition analysis)
- next_action: String (what should happen next)

4. Insight Node
Properties:
// Core
- type: String (payment_behavior/objection_pattern/negotiation_response/communication_style)
- text: String (the actual insight in English)

// Evidence
- from_calls: List[String] (conversation IDs)
- count: Integer (times observed)

// Status
- active: Boolean
- expired: Boolean
- replaced_by: String (insight_id if superseded)

// Relevance
- confidence: String (High/Medium/Low)
- priority: String (High/Medium/Low)
