# Context Voice Bots Collections:

## Description:
* We have a voice bot framework setup for bank EMI collections (reminder calls,  payment confirmation calls etc).
* The voice bot talks with the customer realtime.
* Since, this is being done in India, for now we are supporting only Hindi and English languages.
* The high level architecture uses the following:
    - A LLM is used to generate the text that the bot will speak. (NOTE: Customer profile and other relevant data is provided as context to the LLM to generate personalized conversations).
    - Then a fast TTS converts the text to speech durin the call.
    - Based on the customer response, a speech to text (STT) engine converts the speech to text to get the customer response.
    - The customer response text is again provided as context to the LLM to generate the next response.
    - This continues till the call is completed.
